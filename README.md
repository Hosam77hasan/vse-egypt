## 📖 إيه هو VS Code Egypt؟

VS Code Egypt هو محرر أكواد مصري 100%، مبني على أساس VS Code المفتوح المصدر. الفكرة إننا شلنا متجر الإضافات الخارجي واستبدلناه بـ 3 نماذج ذكاء اصطناعي مدمجة جوه المحرر نفسه، من غير ما المستخدم يحتاج يحمل أي حاجة من بره.

الـ 3 نماذج دول هم:
- 🚗 **السائق (Driver)** — للكتابة السريعة والتعديلات الصغيرة
- 🧭 **القائد (Leader)** — للتحليل العميق والقرارات المعمارية
- 💡 **المبتكر (Innovator)** — للتعديلات الكبيرة وإعادة الهيكلة

## ✨ الميزات الرئيسية

### 🤖 الذكاء الاصطناعي المدمج

الـ 3 نماذج مش إضافات بتنزلها — دي جوه المحرر نفسه:

| النموذج | الاستخدام | الموديل المستخدم |
|---------|----------|-----------------|
| 🚗 السائق (Driver) | كتابة وتعديل سريع للأكواد | DeepSeek Chat |
| 🧭 القائد (Leader) | تحليل معمق وقرارات معمارية | DeepSeek Reasoner |
| 💡 المبتكر (Innovator) | إعادة هيكلة وتعديلات كبيرة | Gemini (عبر OpenRouter) |

- **Ctrl+K**: حدد الكود، اضغط Ctrl+K، اكتب المطلوب — والـ AI يعدل على طول
- **شات جانبي**: دردشة مع الذكاء الاصطناعي في الشريط الجانبي، فاهم سياق الملف المفتوح
- **Agent Mode**: للمشاريع الكبيرة، بيشتغل على ملفات متعددة في نفس الوقت
- **عداد توكينز**: كل خطة ليها حد شهري من التوكينز، بنحسبلك استهلاكك أول بأول

### 🎨 التصميم

- واجهة باللون الليموني `#aacc00` مع أسود `#1e1e1e`

### 🔒 الأمان

- **JWT** — توكنز ترخيص موقعة ومؤمنة

- **Helmet** — حماية رؤوس HTTP
- **Rate Limiting** — منع الهجمات (30 طلب/دقيقة للمستخدم)
- **CORS** — المواقع المسموح لها بس هي اللي تتكلم مع السيرفر
- **SQLite WAL** — قاعدة بيانات سريعة وآمنة
- **Admin Session** — جلسة أدمن منفصلة تمامًا عن جلسات المستخدمين
- **IP Hashing** — عناوين IP بتتجزأ ومش بتتسجل صريحة

## 🔔 نظام الإشعارات (Push Notifications)

لما مستخدم يبعت طلب دفع جديد:

1. **إشعار Web Push** — يوصل للمتصفح عند الأدمن حتى لو المتصفح مقفول
2. **Service Worker** — `sw.js` بيعمل معالجة للإشعارات في الخلفية
3. **VAPID** — مفاتيح Web Push للإشعارات الآمنة
4. **قنوات منفصلة** — إشعارات الطلبات العادية منفصلة عن إشعارات الدفع

الإشعارات شغالة بتقنية Web Push (زي اللي بتستخدمها تطبيقات الويب الحديثة) ومش محتاجة Firebase ولا FCM — شغالة على كل المتصفحات الحديثة.

## 🧩 استراتيجية الإضافات (Extensions Strategy)

### إيه اللي حصل؟

في البداية، كان القرار إننا **نشيل كل الإضافات** من VS Code عشان نخلي المحرر خاص بينا والمستخدمين ميقدروش يحملوا أدوات AI خارجية.

### المشكلة:

لما شلنا الإضافات بالكامل، اكتشفنا إن في **إضافات كتير مفيدة** مش متعلقة بالذكاء الاصطناعي — زي:
- 🎨 **الثيمات والألوان** (Themes)
- 📝 **Formatters** (Prettier, ESLint)
- 🔍 **Linters** (تنسيق وتدقيق الكود)
- 🗂️ **دعم لغات برمجة إضافية**
- 🐳 **Docker, Git, GitHub** وغيرهم

### الحل الجديد (المطلوب):

**منمنعش كل الإضافات — نمنع بس إضافات الذكاء الاصطناعي!**

الاستراتيجية الجديدة:

```
✅ مسموح: الثيمات، Formatters، Linters، لغات برمجة، Git، Docker...
❌ ممنوع: GitHub Copilot، Tabnine، Codeium، Cody، Cursor، Continue،
          Amazon Q، Google Gemini Code Assist، وأي إضافة AI/LLM
```

### إزاي هنطبق ده تقنيًا؟

عندنا 3 طرق ممكنة:

#### الطريقة الأولى: قائمة بيضاء (Allowlist) — **الأفضل**

في ملف `product.json` أو من خلال `extensions.json`، نحدد قائمة بالإضافات المسموح بها:

```json
{
  "extensionsGallery": {
    "serviceUrl": "https://open-vsx.org/vscode/gallery",
    "itemUrl": "https://open-vsx.org/vscode/item"
  },
  "extensionsAllowed": {
    "allowed": [
      "ms-python.python",
      "dbaeumer.vscode-eslint",
      "esbenp.prettier-vscode",
      "..."
    ]
  }
}
```

#### الطريقة الثانية: قائمة سوداء (Blocklist)

نمنع إضافات AI معروفة بالـ ID:

```json
{
  "extensionsBlocked": [
    "github.copilot",
    "github.copilot-chat",
    "tabnine.tabnine-vscode",
    "codeium.codeium",
    "amazonwebservices.amazon-q-vscode",
    "continue.continue",
    "sourcegraph.cody-ai",
    "google.geminicodeassist"
  ]
}
```

#### الطريقة الثالثة: تصفية حسب الكلمات المفتاحية

أي إضافة في وصفها أو اسمها الكلمات دي تترفض:
- `copilot`, `codeium`, `tabnine`, `AI`, `LLM`, `GPT`, `Claude`, `Gemini`, `code assistant`, `code generation`, `autocomplete AI`

### التطبيق العملي:

الباتشات الموجودة في `vse-extension/editor/patches/` تقدر تتعدل عشان:

1. **تسمح بتثبيت الإضافات العادية** من سوق Open VSX
2. **تصفي أي إضافة AI** قبل ما تتثبت
3. **تخفي إضافات AI** من نتائج البحث في المتجر
4. **تظهر رسالة للمستخدم**: "النماذج المدمجة (السائق، القائد، المبتكر) هي البديل المدعوم للذكاء الاصطناعي في VS Code Egypt"

### الملفات المطلوب تعديلها:

| الملف | التعديل |
|-------|---------|
| `product.json` | إضافة `extensionsGallery` وإعدادات `extensionsAllowed` |
| `vse-extension/editor/patches/` | باتش يضيف فلتر للإضافات قبل التثبيت |
| `vse-extension/editor/src/browser/` | واجهة للمستخدم توضح الإضافات المسموحة والممنوعة |

- ✅ المستخدم يقدر يحمل ثيمات وأدوات تنسيق ولغات
