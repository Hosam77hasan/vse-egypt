## 📖 نظرة عامة

VS Code Egypt هو محرر أكواد كامل مبني على أساس VS Code، لكن بدون متجر إضافات، وبذكاء اصطناعي متكامل من جوه بثلاث موديلات مخصصة:

- 🚗 **السائق (Driver)** - للكتابة والتعديل السريع
- 🧭 **القائد (Leader)** - للتحليل والقرارات المعمارية
- 💡 **المبتكر (Innovator)** - لإعادة الهيكلة والتعديلات الكبيرة

## 🔧 التطوير المحلي

### المتطلبات
- Node.js 18+
- npm أو yarn
- Git

### التشغيل
```bash
# استنساخ المستودع
git clone https://github.com/Hosam77hasan/vse-egypt.git
cd vse-egypt

# تثبيت الاعتماديات
cd vse-backend && npm install
cd ../vse-landing && npm install
cd ../vse-payment-portal && npm install

# تشغيل الباك إند
cd vse-backend && npm start

# تشغيل الموقع التسويقي
cd vse-landing && npm start

# تشغيل بوابة الدفع
cd vse-payment-portal && npm start
```

### الاختبارات
```bash
cd vse-backend && npm test -- --coverage
```
